# Courses Directory

This directory contains isolated course silos. Each course maintains its own specifications, architecture plans, tasks, and instructional deliverables.

```
courses/
└── <course-id>/
    ├── README.md         # Course syllabus, description, and outcomes
    ├── specs/            # Iteration specifications (001-..., 002-...)
    └── content/          # Course content, Canvas HTML, labs, guides
```

*Refer to the root [CURRENT.md](file:///c:/dev/Course-Content-Agentic-Template/CURRENT.md) to see or set the active course.*
