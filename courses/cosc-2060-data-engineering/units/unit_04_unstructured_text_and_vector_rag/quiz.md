## Answer Key
| Question # | Correct Answer | Concept Tested & Rationale |
| :--- | :--- | :--- |
| **1** | **B** | Naive character slicing splits words, numbers, and logical thoughts in half, stripping the vector embedding of its intended semantic context. |
| **2** | **B** | Chunk overlap provides contextual continuity so sentences located near boundary splits are fully represented in adjoining chunks. |
| **3** | **B** | HNSW builds hierarchical multi-layer graphs allowing fast logarithmic navigation to nearest neighbor clusters without exhaustive linear scans. |
| **4** | **B** | Exact search (Flat) compares against every vector in O(N); ANN algorithms like HNSW approximate the nearest neighbors in O(log N) time. |
| **5** | **B** | Cosine similarity captures the orientation of vector representations in latent space, neutralizing magnitude distortions from token length variations. |
| **6** | **B** | Hybrid search pairs dense embeddings (great for semantic concepts) with sparse lexical algorithms like BM25 (great for serial numbers and exact IDs). |
| **7** | **B** | Bi-encoders retrieve candidates quickly; cross-encoders process query-document pairs jointly to rank the final context with superior accuracy. |
| **8** | **B** | Irrelevant context in the prompt dilutes attention, increases cost, and distracts the LLM from synthesizing accurate factual answers. |
| **9** | **A** | Metadata payloads allow compound filtering (e.g. WHERE model='X10' AND vector <-> query < 0.3), scoping similarity search to valid records. |
| **10** | **B** | Precision at K (P@K) evaluates how many of the top K retrieved results are relevant to the query task. |
