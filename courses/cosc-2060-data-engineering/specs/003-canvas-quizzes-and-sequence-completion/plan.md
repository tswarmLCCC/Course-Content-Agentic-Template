## 1. Technical Architecture & Approach

### Course Organization & Unit Layout
To enable automatic ingestion by `build_course.py`, we organize the deliverables into unit subdirectories within the sandboxed course folder:

```
courses/cosc-2060-data-engineering/
├── course_config.json                 # Course metadata, grading scale, assignment groups
├── syllabus.md                        # Master institutional syllabus text
├── units/
│   ├── unit_01_relational_foundations/
│   │   ├── overview.md                # Item 1: Roadmap, 300m time budget, objectives
│   │   ├── reading.md                 # Item 2: Core readings & conceptual deep-dive
│   │   ├── drills.md                  # Item 3: Self-check exercises with collapsible answer keys
│   │   ├── lab_guide.md               # Item 4 & 5: Hands-on scenario & grading rubric
│   │   └── quiz.md                    # Item 7: 10 QTI-compliant questions with rationale key
│   ├── unit_02_anomaly_detection_engines/
│   ├── unit_03_visual_sensor_and_multimodal_layer/
│   ├── unit_04_unstructured_text_and_vector_rag/
│   ├── unit_05_data_as_a_service_and_apis/
│   ├── unit_06_agentic_interfaces_and_mcp/
│   ├── unit_07_orchestration_and_automation/
│   └── unit_08_capstone_defense_and_production/
```

### Assessment Architecture (Quizzes)
Each quiz follows the standard format parsed by `qti_builder.py`:
- 10 Multiple-Choice Questions per unit (80 total questions across the course).
- Strict four-option structure (`* A)`, `* B)`, `* C)`, `* D)`).
- Markdown Answer Key table specifying the correct letter and concept rationale.
- Automatic compilation into Canvas QTI 1.2 XML with 20 points possible and 3 allowed attempts.

### Canvas Common Cartridge Build Pipeline
Execution command:
```bash
python .agents/skills/canvas-course-builder/build_course.py \
  --config courses/cosc-2060-data-engineering/course_config.json \
  --units-dir courses/cosc-2060-data-engineering/units \
  --output courses/cosc-2060-data-engineering/COSC_2060_Complete.imscc
```

## 2. ADR Conformance & Constraints

- **ADR-001 (Accessibility)**:
  - All quiz markdown tables include header row alignments (`:--- | :--- | :---`).
  - Self-check drills use native semantic `<details><summary>` HTML tags for screen-reader compatibility.
  - Colors generated by `html_styler.py` adhere to WCAG 2.1 AA (Navy `#1e3a8a`, Slate `#0f172a`, Light `#f8fafc`).
- **ADR-002 (Spec-Driven Development)**:
  - Every quiz question and overview maps to measurable competencies specified in [README.md](file:///c:/dev/Course-Content-Agentic-Template/courses/cosc-2060-data-engineering/README.md).
- **Course Sandboxing**:
  - All unit files, configurations, and compiled `.imscc` outputs remain within `courses/cosc-2060-data-engineering/`.

## 3. Implementation Sequence & Risk Mitigation

1. **Step 1:** Author `course_config.json` and `syllabus.md` for COSC 2060.
2. **Step 2:** Scaffold `units/unit_01_...` through `unit_08_...` populating existing readings, lab guides, and interactive drills.
3. **Step 3:** Author the 8 Unit Overview files (`overview.md`).
4. **Step 4:** Author the 8 Unit Knowledge Check quizzes (10 questions each, 80 total, with complete concept rationales).
5. **Step 5:** Run `build_course.py` to compile the complete Canvas Common Cartridge (`COSC_2060_Complete.imscc`).
6. **Step 6:** Verify XML validity and inspect generated package.
