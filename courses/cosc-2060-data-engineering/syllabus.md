# Course Syllabus: COSC 2060 — Modern Data Engineering & AI Infrastructure

## Course Information
- **Course Code**: COSC 2060
- **Course Title**: Modern Data Engineering & AI Infrastructure
- **Credits**: 3.0 Credit Hours
- **Prerequisites**: Working knowledge of Python and relational SQL fundamentals
- **Instructional Format**: Asynchronous Online with Synchronous Active Learning Clinics
- **Term**: Fall 2026
- **Institution**: Laramie County Community College (LCCC)

---

## 1. Course Description
Modern Data Engineering & AI Infrastructure equips students with hands-on, production-grade skills to build, optimize, and orchestrate modern data pipelines and agentic AI systems. Moving beyond toy scripts and legacy batch architectures, students learn to build high-throughput analytical query engines using columnar vectorization (DuckDB, Polars), real-time anomaly detection pipelines, multimodal feature stores, Retrieval-Augmented Generation (RAG) vector pipelines, asynchronous Data-as-a-Service APIs (FastAPI), Model Context Protocol (MCP) servers for autonomous AI agents, and resilient pipeline orchestration.

---

## 2. Zero-Cost Infrastructure & Textbook Policy
All tools, databases, and libraries used in this course are **100% free and open-source**. There is no mandatory commercial textbook. All required readings, code repositories, and documentation are provided directly in Canvas.

**Primary Software Stack**:
- Python 3.10+
- DuckDB & Polars (Columnar analytics)
- ChromaDB / Qdrant (Vector databases)
- FastAPI & Pydantic (Asynchronous APIs)
- Docker & Docker Compose (Containerized infrastructure)
- Model Context Protocol (MCP) SDK

---

## 3. Course Learning Outcomes (Competencies)
Upon successful completion of this course, students will be able to:
1. Design and optimize high-throughput columnar queries using DuckDB and Polars for fast local data transformation.
2. Implement defensive data quality, schema enforcement, and streaming anomaly detection pipelines.
3. Process multimodal video and image streams into structured feature stores and vector databases.
4. Build semantic search, chunking, and Retrieval-Augmented Generation (RAG) knowledge retrieval pipelines.
5. Architect high-concurrency, asynchronous Data-as-a-Service REST APIs with FastAPI and Pydantic validation.
6. Implement Model Context Protocol (MCP) servers and deterministic tool execution for autonomous AI agents.
7. Orchestrate resilient event-driven pipelines with scheduled DAGs, retry loops, and telemetry alerting.
8. Defend an end-to-end data engineering architecture in a live capstone defense addressing cost, latency, and failure modes.
