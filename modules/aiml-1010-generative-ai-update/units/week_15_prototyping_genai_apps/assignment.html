Week 15 Applied Lab: Prototyping an Interactive Generative AI Application

Assignment Objective: Build and demonstrate a functional generative AI prototype with an interactive user interface using Streamlit, an open LLM or API, and structured prompt orchestration.

Laboratory Instructions & Tasks

Step 1: Application Concept & Use Case

Design a focused enterprise utility (e.g., automated email draft generator with tone adjustment, technical documentation QA assistant, or resume bullet-point optimizer).

Step 2: UI Implementation in Streamlit

Build an interactive web interface using Streamlit (or Gradio). Implement user controls: text area inputs, parameter sliders (temperature, max tokens), tone selection dropdowns, and a primary generation trigger button.

Step 3: Backend Orchestration & Error Handling

Connect the UI to an LLM provider (Ollama local inference, Google Gemini API, OpenAI, or Hugging Face Inference API). Implement error handling for rate limits, empty inputs, and streaming token responses.

Step 4: Prototype Code & Screencast Submission

Submit your Python application code (`app.py`), `requirements.txt`, and a concise PDF walkthrough (with UI screenshots or a link to an unlisted demo video) documenting user testing and latency observations.
