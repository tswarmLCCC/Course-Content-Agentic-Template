Week 03 Applied Lab: Controlled Generation with the RGC Framework

Assignment Objective: Apply the Role-Goal-Context (RGC) framework, delimiters, and few-shot formatting constraints to engineer robust, deterministic outputs from generative language models.

Laboratory Instructions & Tasks

Step 1: Baseline Prompt Formulation

Draft a baseline, unconstrained prompt for a specific professional task (e.g., extracting action items from meeting notes, draft incident response email, or customer inquiry triage). Run the baseline across 3 distinct queries and record output variance.

Step 2: Applying the RGC Architecture

Re-engineer your prompt incorporating explicit Role definition, granular Goal specifications with strict output schema (e.g., Markdown table or JSON), and realistic Context constraints (e.g., tone, word count ceilings, forbidden terminology).

Step 3: Few-Shot In-Context Grounding

Incorporate at least two diverse input-output demonstration pairs into the context window. Test how few-shot conditioning enforces schema adherence and eliminates hallucinated formatting.

Step 4: Comparative Audit & Submission

Compile a structured laboratory report showing side-by-side prompt iterations, model outputs, a breakdown of how each RGC component altered model latent steering, and your finalized master prompt template.
