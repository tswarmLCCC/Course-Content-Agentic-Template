## 1. Module Overview & Pedagogical Value Proposition

As documented in Google's landmark whitepaper (*The New SDLC With Vibe Coding*), the software development industry is undergoing a structural paradigm shift. Syntax friction is collapsing—roughly 41% of all new code is generated by artificial intelligence. However, casual prompt-and-pray development (**"Vibe Coding"**) creates an unsustainable technical debt bubble: low upfront capital cost (CapEx), but astronomical ongoing maintenance cost (OpEx), context pollution, and the dreaded "80% trap."

**Agentic Software Engineering** provides the engineering rigor to build production systems with AI. This 3-unit standalone modular package teaches undergraduate students to operate as **Conductors** and **Orchestrators** rather than mere syntax typists.

- **Target Deliverable**: `Agentic_Software_Engineering_Modules_Import.imscc`
- **Import Strategy**: Non-destructive modular import. Drops directly into any Canvas course without modifying host syllabi, front pages, or course settings.
- **Runtime Environment**: Dual-backend hybrid supporting **Google Gemini API** (cloud) and **Local Ollama with Qwen 2.5 Coder 7B/14B** (100% offline, zero-cost execution).
